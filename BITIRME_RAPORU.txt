================================================================================
			DÖNEM İÇİ YAPILAN ÇALIŞMALARIN ÖZETİ
================================================================================

Bu dönemde, evcil hayvan sahiplerinin hayvanlarını kayıt altına alabilecekleri, diğer hayvan sahipleriyle iletişim kurabilecekleri, hayvanlarını çiftleştirme veya sahiplendirme amacıyla eşleştirebilecekleri ve evcil hayvan ürünleri satın alabilecekleri kapsamlı bir mobil uygulama geliştirilmiştir.

YAPILAN TEMEL ÇALIŞMALAR:

1. Mobil Uygulama Geliştirme: Flutter framework kullanılarak Android ve iOS platformlarında çalışabilen cross-platform mobil uygulama geliştirilmiştir. Riverpod state management ve GoRouter navigasyon yapısı kullanılmıştır.

2. Backend API Geliştirme: Node.js ve Express.js kullanılarak RESTful API mimarisi ile backend sunucu oluşturulmuştur. 17 farklı controller ve 21 route dosyası ile kapsamlı bir API yapısı kurulmuştur.

3. Veritabanı Tasarımı: MongoDB NoSQL veritabanı kullanılarak 19 farklı veri modeli tasarlanmıştır. Mongoose ODM ile veritabanı işlemleri yönetilmektedir.

4. Kimlik Doğrulama Sistemi: JWT (JSON Web Token) tabanlı güvenli kimlik doğrulama sistemi implement edilmiştir. Access token ve refresh token mekanizması kullanılmaktadır.

5. Gerçek Zamanlı Mesajlaşma: Socket.IO kütüphanesi kullanılarak anlık mesajlaşma altyapısı kurulmuştur. Kullanıcılar arasında gerçek zamanlı iletişim sağlanmaktadır.

6. E-Ticaret Modülü: Sepet yönetimi, sipariş oluşturma, ödeme işlemi ve sipariş takibi özellikleri geliştirilmiştir. Satıcı paneli ve ürün yönetim sistemi oluşturulmuştur.

7. Eşleştirme Sistemi: Evcil hayvanların çiftleştirme ve sahiplendirme amaçlı eşleştirilmesi için swipe tabanlı eşleştirme algoritması geliştirilmiştir.

8. Dosya Yükleme Sistemi: Multer kütüphanesi ile fotoğraf yükleme ve yönetim sistemi kurulmuştur.

a) MATERYAL LİSTESİ:

FRONTEND (MOBİL UYGULAMA):
- Flutter SDK 3.x: Cross-platform mobil uygulama geliştirme framework'ü

- Riverpod: State management çözümü

BACKEND:
- Node.js v18+: JavaScript runtime ortamı
- Express.js: Web application framework
- MongoDB: NoSQL veritabanı
- Mongoose: MongoDB ODM (Object Document Mapper)
- Socket.IO: Gerçek zamanlı WebSocket iletişimi
- JSON Web Token (JWT): Kimlik doğrulama
- Bcrypt: Şifre hashleme
- Nodemailer: E-posta gönderimi
- Multer: Dosya yükleme middleware
- Helmet: HTTP güvenlik başlıkları
- CORS: Cross-Origin Resource Sharing
